# Meva KÜÇÜKAKYÜZ Portfolyosu

Bu proje, ders kapsamında Meva KÜÇÜKAKYÜZ için bir sanatçı portfolyosu hazırlamak amacıyla oluşturulmaktadır.

## Proje bilgileri

- Öğrenci: Cem MÜLAZIMOĞLU
- GitHub kullanıcı adı: `cemmlzmgl`
- Planlanan depo adı: `portfolio`
- İçerik kaynağı: Proje klasöründeki Meva Küçükakyüz CV PDF'si

## Sayfalar

- `index.html` — Ana Sayfa
- `biyografi.html` — Biyografi
- `calismalar.html` — Çalışmalar
- `galeri.html` — Galeri
- `iletisim.html` — İletişim
- `yonetim.html` — Çalışma Yönetimi

## İlerleme

- Birinci hafta: Sayfa iskeletleri ve ortak gezinme hazırlandı.
- İkinci hafta: CV'den alınan gerçek metinler, tiyatro tabloları, portre ve galeri fotoğrafları eklendi.
- Şu an sayfalarda yalnızca HTML kullanılıyor.
- İletişim formu üçüncü haftada, CSS ve JavaScript ise sonraki aşamalarda hazırlanacaktır.
- Proje henüz GitHub'a yüklenmemiştir.

## Çalıştırma

1. Proje klasörünü VS Code ile açın.
2. `index.html` dosyasını açın.
3. Live Server eklentisi yüklüyse, dosyaya sağ tıklayıp **Open with Live Server** seçeneğini seçin.
